# Установка игрового ПК без команд и секретов

Для каждого игрового ПК подготовьте отдельный приватный пакет. Оператор на ПК
распаковывает архив и запускает только `install-agent.cmd` от имени
администратора.

Для бездисковой загрузки не добавляйте этот пакет и реальный `core_token` в общий
master-образ. Конфиг и токен должны появиться в приватном слое конкретного ПК до
автозапуска Agent; состояние сессии должно переживать перезагрузку или восстанавливаться
из отдельного постоянного хранилища. Эта последовательность пока не проверена с CPB
на физическом оборудовании.

В корне архива положите файл `clubpay-agent-enrollment.json`:

```json
{
  "external_pc_id": "pc-001",
  "controller_url": "http://192.168.1.10:8080",
  "core_token": "..."
}
```

`external_pc_id` должен точно совпадать с ПК, созданным в ClubPay. Установщик
до копирования файлов проверяет связь с Controller, авторизацию и наличие
платёжного QR. Если что-либо не готово, установка останавливается и не оставляет
на игровом ПК старый или пустой конфиг.

Файл содержит клубный секрет. Не отправляйте его игрокам или в чат, не храните в
общей папке и удаляйте исходный архив после развёртывания. В дальнейшем этот
файл будет скачиваться из панели как одноразовый пакет привязки, а не собираться
вручную.
